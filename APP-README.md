# WhatDoTheyKnow FOI requests

Freedom of Information requests about Great House Farm (Tŷ Mawr), Llandough, made on WhatDoTheyKnow: each thread as a send/receive view rendered from JSON, with every attachment shown from the Wayback Vault.

Built by `work/wdtk-site/build_site.py` from `data/*.json`. The static site is in `public/` (Cloudflare Pages; no build step at the static-site root). Release 1.0.2 improves the narrow-screen summary grid; request totals and thread records are unchanged.
